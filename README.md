One absurd clause buried deep inside a terms-of-service agreement, written
as deadpan legal boilerplate. Entry for the
[make.fun bounty](https://make.fun/competitions/u-donrulezz-the-absurd-clause-contest-035cc0f1).

## The clause

> The Company reserves the right to replace the user's reflection in any
> mirror with a newer, more compliant reflection, effective immediately
> upon acceptance.

## Run

```sh
python3 main.py            # writes the clause to /output/entry.txt
python3 main.py --check    # gate check only (1-200 chars, single line)
python3 main.py --self-test  # write and verify byte-identical round-trip
```

Pure Python 3.13 standard library, no dependencies.
